**Verdict — still photos on Sony a7C with Sigma MC-11 + Sigma 85mm F1.4 DG HSM Art: AF-S works; AF-C does not; DMF works only with the required Sigma USB Dock setting.**

Reasons:
- The knowledge base entry `adapter_compatibility/sigma_mc11` lists the **Sony α7C** among Sigma’s checked compatible E-mount bodies for MC-11.
- In the same entry’s per-lens table, **85mm F1.4 DG HSM Art** is marked:
  - **AFS: supported**
  - **AFC/AFA: not supported**
  - **DMF: supported**
- The same source summary says **DMF requires changing settings via the Sigma USB Dock** for lenses where DMF is available.
- For movies/video, the MC-11 summary says to use **manual focus**, so don’t expect video AF behavior from this setup.

What to do:
- Use **AF-S** for autofocus stills.
- Do **not** use **AF-C** for tracking/action with this adapter setup.
- For **DMF**, configure the lens/adapter setup with the **Sigma USB Dock** first; otherwise DMF may not behave as expected.
- For video, plan on **manual focus**.
