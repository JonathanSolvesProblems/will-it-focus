Verdict: on a Sony a6400 with the MC-11, the Sigma 50mm F1.4 DG HSM Art supports AF-S and DMF, but AF-C is not supported.

Why:
- The MC-11 compatibility list includes the α6400 as a tested/compatible Sony E-mount body.
- The per-lens table lists the Sigma 50mm F1.4 DG HSM under Art with AFS marked supported and DMF marked supported.
- The same MC-11 source says AF-C is not supported on any body, and AFC/AFA are unsupported for all listed lenses.
- For movies, the source says to use MF.

What to do:
- Use AF-S for stills if you want autofocus.
- Use DMF if you want to focus with autofocus first, then fine-tune manually.
- Don’t expect AF-C tracking with this adapter/lens combo.
- If you’re shooting video, plan on manual focus.
