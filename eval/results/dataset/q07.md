On a Sony a7 IV with the Sigma MC-11, the Sigma 150-600mm F5-6.3 DG OS HSM | Contemporary is supported for AF-S and DMF, but AF-C is not supported.

Reasons:
- Sigma’s MC-11 lens table for this exact lens says: “150-600mm F5-6.3 DG OS HSM ○ × ○” — Sigma, MC-11 lens compatibility table, p. 1. The table key is AFS / AFC/AFA / DMF, so that row means AFS supported, AFC/AFA not supported, DMF supported.
- Sigma also has a broader MC-11 compatibility note: “The camera's AF-C is not supported.” — Sigma, MC-11 camera compatibility table, p. 1. That reinforces that continuous AF is not available with the MC-11 setup.
- I did not find a focus caveat tied specifically to the a7 IV + this lens + MC-11 combination. The only MC-11 caveat in the dataset is for teleconverters, and it does not apply here.

What to do:
- Use AF-S or DMF if you’re shooting stills with this setup.
- Do not expect AF-C tracking to work through the MC-11.
- For video, the dataset also says: “Please use MF when shooting movies.” — Sigma, MC-11 lens compatibility table, p. 1, so manual focus is the safest assumption for movie work through this adapter.
