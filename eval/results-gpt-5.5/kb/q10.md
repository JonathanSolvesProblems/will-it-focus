Verdict: On a Sony a6100 with the Sigma MC-11 and Sigma 30mm F1.4 DC HSM Art, AF-S is supported for stills; AF-C is not supported; DMF is not supported.

**Still photos**
- **AF-S / single AF:** supported. The knowledge base entry `adapter_compatibility/sigma_mc11` summarizes Sigma’s MC-11 lens table as listing the **30mm F1.4 DC HSM** with AFS marked supported.
- **AF-C / continuous AF:** not supported. The same entry says AFC/AFA are unsupported for all listed lenses on the MC-11.
- **DMF:** not supported for this lens. In the same per-lens table, the 30mm F1.4 DC HSM has DMF marked unsupported.

**Video**
- The same MC-11 summary says Sigma instructs users to use **manual focus** when shooting movies with the MC-11.

**What to do**
- Use **AF-S** for stills.
- For moving subjects or tracking, don’t rely on AF-C with this adapter/lens combination; use manual focus or a native Sony E-mount lens instead.
- Don’t expect DMF override behavior with this lens on the MC-11.
