**Verdict — Sony a7 IV + Sigma MC-11 + Sigma 35mm F1.4 DG HSM Art: AF-S works for stills; AF-C does not; DMF does not.**

**Reasons**

- **Body coverage:** The Sony **α7 IV** is included in Sigma’s MC-11 compatible Sony E-mount body list, according to the knowledge-base entry `adapter_compatibility/sigma_mc11`, citing `sigma-mc-11-camera-compatibility.pdf`.
- **Still-photo AF-S:** For the **Sigma 35mm F1.4 DG HSM Art**, the MC-11 per-lens table marks **AFS as supported**, summarized in `adapter_compatibility/sigma_mc11`, citing `sigma-mc-11-lens-compatibility.pdf`.

- **DMF:** The table marks **DMF as not supported** for the Sigma 35mm F1.4 DG HSM Art on MC-11.
- **Video:** The MC-11 summary says to use **manual focus for movies**, so don’t expect autofocus behavior there.

- Use **AF-S** for still photos.
- Do **not** use **AF-C** with the MC-11; missed tracking focus is expected because AF-C is unsupported.
- Do **not** rely on **DMF** with this lens on MC-11; it is not supported for this specific lens.
- For video, switch to **MF**.
