**Verdict: on a Sony a9 II with Sigma MC-11, the Sigma 120-300mm F2.8 DG OS HSM Sports supports AF-S for photos, does not support AF-C, and does not support DMF.**

Reasons, from the knowledge-base summary of Sigma MC-11 compatibility:

- The Sony **α9 II / a9 II** is on Sigma’s verified MC-11 E-mount body list. Source file cited by KB: `sigma-mc-11-camera-compatibility.pdf`.
- For the **120-300mm F2.8 DG OS HSM Sports**, the MC-11 lens table lists:
  - **AFS: supported**
  - **AFC/AFA: not supported**
  - **DMF: not supported**  
  Source file cited by KB: `sigma-mc-11-lens-compatibility.pdf`.
- For **movies/video**, the KB summary says Sigma requires **MF** with MC-11. Source file cited by KB: `sigma-mc-11-lens-compatibility.pdf`.

What to do:

- For stills: use **AF-S**.
- For moving subjects where you wanted tracking: **AF-C is not available through MC-11** for this combination; use manual focus or a different lens/adapter/body combination covered for continuous AF.
- For DMF: this lens is listed as **not DMF-compatible** on MC-11, so the USB Dock DMF workaround mentioned for some lenses does not apply here.
- For video: use **manual focus**.
