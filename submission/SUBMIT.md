## 2. Paste the post

The finished post is `submission/devto-post.md`. It already follows the template's sections
(What I Built, Demo, Code, How I Used Sanity, Sanity Project Details), embeds the demo video,
and carries the project ID `qnl9jh8n`.

- If the editor shows ONE markdown box that begins with `---`: select all, paste the whole file,
  and change `published: false` to `published: true` before saving.
- If the editor shows separate Title, Tags and Cover image fields: paste everything from
  `*This is a submission for the ...` down into the body, then set
  Title: `Will It Focus: 21 of 22 Quotes Word for Word From the Manufacturer's Own Documents`,
  Tags: `devchallenge, sanitychallenge, sanity, ai`,
  Cover image: upload `submission/images/verdict-sigma.png`.

Preview once, read the embed and the two images, then Publish.

## 3. After publishing

Send the post URL back for the logged-out proofread and the #sanitychallenge tag check.
Then add `Write-up on DEV: <post url>` under the code link in the YouTube description.
